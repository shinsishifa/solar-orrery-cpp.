# 🪐 Cosmos Vision: Interactive Solar System Orrery

**Cosmos Vision** is a non-game, scientific interactive visualization app built using HTML5 Canvas, CSS3, and Vanilla JavaScript. It simulates the orbits of our solar system's planets around the Sun in real-time, allowing users to inspect planetary data and adjust orbital time dilation.

---

## 🌟 Key Features

* **Real-Time Orbital Simulation:** Calculates planetary velocities and trajectories dynamically around a glowing Sun.
* **Interactive Planet Inspector:** Click on any planet to view scientific data, distances, and orbital periods.
* **Time Controls:** Adjust simulation speeds from pause to warp speed instantly.
* **Modular Multi-File Architecture:** Cleanly organized into `index.html`, `style.css`, and `script.js`.
